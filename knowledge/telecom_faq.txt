1. GENERAL TELECOM QUESTIONS
============================================================

Q: What is a telecom service?

A:
A telecom service provides communication services such as mobile calls,
SMS, mobile data, internet connectivity, roaming and related services.

Q: What services can a mobile telecom operator provide?

A:
Common services include:
- Voice calls
- SMS
- Mobile internet
- 4G connectivity
- 5G connectivity
- International roaming
- Recharge services
- Data add-ons
- SIM services
- eSIM services
- Number portability
- Customer support

Q: What is a mobile plan?

A:
A mobile plan is a subscription package that defines available data,
calls, SMS, validity period and other benefits.

Q: What is plan validity?

A:
Plan validity is the period during which the benefits of a plan remain
active.

Q: What happens when my plan expires?

A:
When a plan expires, its included benefits may no longer be available.
The exact behavior depends on the account and plan configuration.

Q: How can I check my current plan?

A:
TelecomAI can retrieve the current plan from the customer subscription
database when the customer ID is available.

Q: How can I check my account status?

A:
TelecomAI can check whether an account is active or suspended using the
customer account database.

Q: What is an active account?

A:
An active account is an account currently allowed to use its configured
telecom services.

Q: What is a suspended account?

A:
A suspended account is an account for which telecom services may be
restricted or disabled.

customer.

A:
A data allowance is the amount of mobile data included in a plan.

Q: What happens when I use all my plan data?

The exact behavior depends on the plan configuration. Possible behavior

Q: Why is my internet slow even though I have data remaining?

A:
Possible reasons include:
- Weak signal
- Network congestion
- High latency
- Packet loss
- Tower problems
- Device configuration
- Network outage
- Poor coverage

Q: Can high network traffic reduce internet speed?

A:

3. INTERNET SPEED
============================================================

Q: What is download speed?

A:
Download speed represents how quickly data can be received from the
internet.

Q: What is upload speed?

A:
Upload speed represents how quickly data can be sent to the internet.

Q: Why is download speed low?

A:
Possible causes include:
- Weak signal
- Network congestion
- Poor coverage
- High latency
- Packet loss
- Tower degradation
- Device limitations
- Network outage

Q: Why is upload speed lower than download speed?

A:
Many mobile networks allocate different amounts of capacity to download
and upload traffic. Therefore upload speed can normally be lower.

Q: What is a speed test?

A:
A speed test measures network performance such as download speed,
upload speed and latency.

Q: Is speed test result always constant?

A:
No. Speed can change depending on network load, location, signal,
device, time of day and server selection.

4. LATENCY
============================================================

Q: What is latency?

A:
Latency is the time required for data to travel between the device and
the destination server.

Q: Is lower latency better?

A:
Generally, lower latency means faster response time for interactive
applications.

Q: Why is my latency high?

A:
Possible causes include:
- Network congestion
- Long network routing paths
- Tower issues
- Poor signal
- Packet loss
- Internet routing problems

Q: What problems can high latency cause?

A:
High latency can affect:
- Online gaming
- Video calls
- Remote desktop
- Interactive applications
- Real-time communication

Q: What is acceptable latency?

A:
The appropriate latency depends on the application. Interactive
applications generally benefit from lower latency.

5. PACKET LOSS
============================================================

Q: What is packet loss?

A:
Packet loss occurs when some network packets fail to reach their
destination.

Q: What causes packet loss?

A:
Possible causes include:
- Weak signal
- Network congestion
- Wireless interference
- Faulty network equipment
- Network instability
- Tower problems

Q: What happens when packet loss is high?

A:
High packet loss can cause:
- Connection drops
- Slow browsing
- Poor voice calls
- Video buffering
- Gaming problems
- Video call interruptions

Q: How can packet loss be reduced?

A:
Possible actions include:
- Moving to an area with stronger signal
- Switching network modes when appropriate
- Checking for network outages
- Restarting network connectivity
- Contacting support if the problem continues

6. SIGNAL STRENGTH
============================================================

Q: What is signal strength?

A:
Signal strength represents how strong the wireless signal received by a
device is.

Q: What does dBm mean?

A:
dBm is a unit commonly used to represent received radio signal power.

Q: Is -70 dBm better than -95 dBm?

A:
Yes. In general, a value closer to zero represents stronger received
signal power.

Q: Why is my signal weak?

A:
Possible reasons include:
- Distance from the tower
- Buildings
- Walls
- Underground locations
- Terrain
- Network coverage
- Indoor interference
- Temporary tower problems

Q: How can I improve signal strength?

A:
Possible steps include:
- Move near a window
- Move outdoors
- Move to a more open area
- Restart network connectivity
- Check network mode
- Check for local outages

8. 5G QUESTIONS
============================================================

Q: What is 5G?

A:
5G is a newer generation of mobile network technology designed to
provide higher capacity, higher speeds and potentially lower latency.

Q: Why is my 5G slow?

A:
Possible causes include:
- Network congestion
- Weak 5G signal
- Tower load
- Backhaul limitations
- Device limitations
- Poor coverage
- Packet loss

Q: Why does my phone show 5G but internet is slow?

A:
The 5G indicator only shows that the device is connected to a 5G
network. Actual performance can still be affected by congestion,
signal quality, latency and other network conditions.

Q: Does 5G always provide faster speed than 4G?

A:
5G is designed for higher performance, but actual speed depends on
coverage, spectrum, network load, device capability and other factors.

Q: Does 5G consume more battery?

A:
Battery usage depends on the device, network conditions and how the
device manages 4G and 5G connectivity.

Q: Why does my phone frequently switch between 4G and 5G?

A:
This can happen when 5G coverage changes or the device moves between
areas with different network conditions.

9. NETWORK CONGESTION
============================================================

Q: What is network congestion?

A:
Network congestion occurs when many users or devices compete for
available network capacity.

Q: How does congestion affect users?

A:
Congestion can cause:
- Lower download speed
- Lower upload speed
- Higher latency
- Higher packet loss
- Connection instability

Q: Why is my internet slower during evening hours?

A:
Network traffic can increase during busy periods, potentially causing
higher network utilization and lower performance.

Q: Can TelecomAI detect congestion?

A:
Yes. TelecomAI can analyze network metrics such as active users,
download speed, latency and packet loss to identify potentially
degraded network conditions.

============================================================

Q: What is a network outage?

A:
A network outage is a period when a network service or network
component is unavailable or significantly degraded.

Q: How can I check whether there is an outage?

A:
TelecomAI can check the simulated outage database for active outages
associated with a tower or location.

Q: What information is useful when checking an outage?

A:
Useful information includes:
- Customer location
- Tower
- Technology
- Outage status
- Start time
- Reason
- Affected area

Q: What should I do during a network outage?

A:
If an active outage is confirmed, the customer may wait for service
restoration or create a support ticket for additional assistance.

Q: Can TelecomAI distinguish an outage from an individual device problem?

A:
TelecomAI can compare customer symptoms with network status, tower
health and outage information. This can help determine whether the
problem may be network-wide or customer-specific.

Q: What is a SIM card?

Q: Why is my SIM not working?

A:
Possible causes include:

- Network configuration issue
- Device compatibility problem
- SIM activation issue

Q: What should I do if my phone says No SIM?

1. Remove and reinsert the SIM.

============================================================
39. TECHNICAL TERMS
============================================================

Q: What is bandwidth?

A:
Bandwidth represents the capacity available for transmitting data.

Q: What is throughput?

A:
Throughput is the actual amount of data successfully transmitted over
a network during a period.

Q: What is jitter?

A:
Jitter represents variation in packet arrival time and can affect
real-time communication.

Q: What is packet loss?

A:
Packet loss occurs when transmitted packets fail to reach their
destination.

Q: What is network congestion?

A:
Network congestion occurs when demand for network resources becomes
high relative to available capacity.

Q: What is a network tower?

A:
A network tower is infrastructure used to provide wireless network
coverage to mobile devices.

Q: What is backhaul?

A:
Backhaul connects access network infrastructure such as towers to the
core network or wider network infrastructure.

42. TELECOMAI RESPONSE BEHAVIOR
============================================================

When answering customer questions, TelecomAI should:

1. Identify the customer's intent.

2. Use customer-specific tools when account information is required.

3. Use network tools for network-related questions.

4. Use billing tools for billing questions.

5. Use the knowledge base for general telecom explanations.

6. Use the RAG system when a question requires telecom documentation.

7. Use diagnostic tools when network metrics are available.

8. Check outage information when the customer reports local network
   problems.

9. Explain technical results in simple language.

10. Never invent customer account information.

11. Never invent billing information.

12. Never claim that an outage exists without checking available
    outage data.

13. Never automatically execute account-changing or financial actions.

14. Require explicit customer confirmation before:
    - Plan changes
    - Recharge
    - Other financial actions
    - Account-changing operations

15. If the available information is insufficient, clearly state what
    information is required.
