ROAMING POLICY

Roaming allows a subscriber to use mobile services outside the normal home network area.

Roaming charges can depend on the destination, service type and active roaming package.

Before international travel, customers should verify whether their plan includes roaming.

Customers should check roaming data settings before using mobile data internationally.

Unexpected roaming charges should be reviewed against the billing record.

If a customer believes a roaming charge is incorrect, the charge should be investigated using the billing system.

The telecom support system should not promise a refund without an authorized billing process.

Support agents should explain the charge and create a billing ticket when further investigation is required.
